新通教育学习平台是面向雅思学习业务的传统 Web 与后端平台，覆盖课程、题库、练习、会员、营销、用户和内容管理等模块。

## 我做了什么

- 参与 Vue 2 Web 与 Spring Boot 3 / Java 17 后端开发，结合 MyBatis-Plus、MySQL、Redis、RabbitMQ 和 Sa-Token 完成跨端业务需求。
- 重建官网 SEO 交付链路，为核心公开页面生成构建期可抓取产物，并增加发布校验门禁。
- 修复公开页面登录态失效与路由跳转问题，完善标签、会员批量导入和 SCRM 推送链路。
- 参与跨产品身份接入与用户来源标记，覆盖方案设计、接口实现、测试和分支交付。

## 我的关注点

这类平台的难点不在单个页面，而在课程、用户、会员、内容和营销数据之间的长期协作。我更关注跨模块链路是否清晰，以及改动能否安全发布、持续验证。
