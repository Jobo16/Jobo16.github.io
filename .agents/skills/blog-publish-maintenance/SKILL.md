# Blog Publish Maintenance

Use this skill when organizing or publishing Quartz content.

## Rules

- Keep `projects/` and `notes/` flat.
- Keep assets in `content/assets/`.
- Do not create category directories for a small number of pages; use tags.
- Preserve old published paths with `aliases` when moving a page.
- Run `npm run check` and `npm run build:optimized` before publishing.
- Review all changed public pages for privacy and broken links.
